# UI 设计变更记录

## M3-R 编辑器生产闭环 - 2026-08-16

- 根据生产验收反馈完成 M3 重构，编辑器改用 Fabric.js MIT 作为交互内核。
- 图片所有者和平台管理员可从图片详情进入编辑器，个人空间卡片也提供直接编辑入口；访客和其他用户不展示按钮。
- 业务状态重做为 `EditorState v2`，不持久化 Fabric 私有 JSON。
- 工作区加入裁切工具、图层列表、对象属性、完整图片调节入口和统一保存状态。
- 顶部加入退出编辑入口和三动作确认：可保存草稿退出、不保存并回退本次会话，或继续编辑；退出固定返回图片详情页。
- 草稿加入 revision 乐观并发控制，自动保存、退出、正式版本保存和恢复串行提交，陈旧窗口不再覆盖新草稿。
- 预览与 PNG 导出统一使用自有 Canvas 滤镜管线，裁切与 14 项图片调节（含高光、阴影和锐度）全部通过专项测试。
- 真实注册、MinIO 上传、完整编辑、版本保存/恢复 Playwright 流程通过；1440×900、1024×768、390×844 三视口人工走查通过。

## M3 单人编辑器与版本 - 2026-08-16

- `/editor/[pictureId]` 落地为深色单人编辑工作区，桌面左右分栏，移动端上下布局。
- 选择、画笔、马克笔、擦除、文字、旋转、缩放和撤销重做已可用；工具状态和计数保持稳定尺寸。
- 图片调节侧栏接入结构化参数，草稿 800ms 防抖自动保存，保存状态在顶部持续可见。
- 版本历史抽屉展示缩略图、来源、创建者和恢复入口；恢复后回到当前画布并保留后续历史。
- 版本预览和导出统一经后端鉴权资源接口，未引入前端假数据或第二套图片存储。

## M2 AI 创作闭环 - 2026-08-13

- `/ai/create` 和 `/ai/tasks` 已落地，模型、比例、清晰度和配额全部来自后端。
- 创建页使用参数面板 + 冷灰网格画布；任务中心桌面使用紧凑表格，移动端切换为任务列表。
- 增加 loading、empty、error、permission denied、取消反馈、失败原因和额度返还状态。
- 任务结果预览与下载只使用后端图片资源 URL，未引入前端假数据或第二套存储。

## v1.1 实现进度 - 2026-08-12

- 已将 M1 公共图库、图片详情、登录注册、个人空间、图片上传和公开审核页面落地为 v1.1 视觉。
- 公共页面使用顶部导航与图片优先瀑布流，业务与管理页面使用冰蓝灰侧栏工作台。
- 已补充页面进入、图片悬停、表单进入和预览切换动效，并适配减少动态效果偏好。
- 删除前端推算的浏览、点赞和空间容量指标，仅展示后端真实提供的数据。
