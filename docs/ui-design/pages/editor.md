# 图片编辑器

- 路由：`/editor/[pictureId]`
- 里程碑：单人编辑 M3；实时协作 M5
- 参考图：[editor.png](../references/editor.png)

## 布局

- 深色无干扰画布。
- 左侧固定工具栏，中间画布，右侧属性和图层面板。
- 顶部展示保存状态、缩放、版本历史、在线成员和导出。
- 所有工具和计数器使用稳定尺寸，状态变化不能推动布局。

## 能力

- 旋转、裁切、缩放、涂鸦、擦除、文字和图片调节。
- 编辑数据结构化保存，支持草稿与正式版本。
- 协作阶段展示在线成员、光标、软锁、重连和冲突状态。

编辑器底层库和协作算法未决策前，产品图只定义界面和交互目标，不定义持久化格式。
