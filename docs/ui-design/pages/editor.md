# 图片编辑器

- 路由：`/editor/[pictureId]`
- 里程碑：单人编辑 M3；实时协作 M5
- 状态：M3-R 已完成开发闭环；M5 实时协作仍为规划
- 参考图：[editor.png](../references/editor.png)

本页保存 M3/M5 设计方向。M3-R 采用 Fabric.js MIT 作为交互内核，并由自有 `EditorState v2`、滤镜和导出管线保证业务状态不绑定第三方 JSON；结构化草稿和不可变版本由后端 `/api/v1` 持久化。

## 布局

- 深色无干扰画布。
- 左侧固定工具栏，中间画布，右侧属性和图层面板。
- 顶部左侧提供带 Tooltip 的返回箭头；同时展示保存状态、缩放、版本历史和导出。在线成员属于 M5 规划能力。
- 所有工具和计数器使用稳定尺寸，状态变化不能推动布局。

## 能力

- 旋转、裁切、缩放、涂鸦、擦除、文字和图片调节。
- 编辑数据结构化保存，支持草稿与正式版本。
- 协作阶段展示在线成员、光标、软锁、重连和冲突状态。

M3-R 实现与验收：

- 当前重构工具包括选择、裁切、画笔、马克笔、擦除、文字、旋转和缩放，并提供结构化图层列表和对象属性。
- 图片调节覆盖曝光、亮度、对比度、高光、阴影、饱和度、自然饱和度、色温、色调、锐度、褪色、暗角、增强和去雾；所有项目必须通过预览/导出一致性验收。
- 草稿 800ms 防抖自动保存；版本保存时导出 PNG 预览，经后端写入私有 MinIO。
- 点击退出后弹出三动作对话框：“保存草稿并退出”“不保存并退出”“继续编辑”。前两项完成后固定返回图片详情页；不保存只回退本次会话，最近一次正式版本保存或恢复会成为新的回退基线。
- 退出保存、回退、正式版本保存和恢复与自动保存串行执行，并使用 revision 防止多窗口陈旧状态覆盖；冲突时留在编辑器并提示重试。
- 桌面端为深色画布与右侧属性/图层面板；平板和手机切换为上下布局，但复杂编辑仍以桌面为主。
- 原图、草稿和版本列表分别提供 loading、error、permission denied 和 retry 状态；任何失败不得静默退化为新空白草稿。
- 1440×900、1024×768 和 390×844 三视口已完成 Playwright 截图人工走查；桌面保持四区结构，手机首屏可见导出与保存入口且无横向溢出。
- 真实 Playwright 流程覆盖完整编辑、PNG 导出、MinIO 版本预览和不可变版本恢复；M3-R 于 2026-08-16 关闭。

编辑器底层库和协作算法未决策前，M5 产品图只定义界面和交互目标，不定义协作持久化格式。
