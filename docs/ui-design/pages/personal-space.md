## 目标

管理默认个人空间中的图片和公开审核状态。

## 布局

- 浅蓝灰固定侧边栏，白色顶部栏。
- 顶部品牌横幅只承载简短欢迎和关键提醒。
- 概览数据使用同级白色卡片，不制作多层嵌套卡片。
- 图片使用规则网格，当前在客户端进行状态筛选。

## 当前实现

- 图片总数、审核中、已公开和私有图片数。
- 状态筛选。
- 上传入口、详情入口和单张提交审核。

空间容量、趋势分析、AI 配额和团队数量必须等待真实接口或对应里程碑。

服务端分页与 URL 查询状态尚未接入；实现时必须同步 API 适配、查询缓存和返回位置行为。
