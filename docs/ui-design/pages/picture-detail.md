# 图片详情

- 路由：`/pictures/[pictureId]`
- 里程碑：公开查看 M1；下载、评论和分享 M6
- 状态：M1 查看与公开审核状态、M3 所有者编辑入口、M6 下载/分享/评论/批注已实现
- 参考图：[picture-detail.png](../references/picture-detail.png)

## 目标

以大图为主，提供作者、元数据、公开审核状态和围绕当前图片的讨论操作。

## 权限

- 访客可以查看审核通过的图片。
- 所有者可以查看私有图片状态，并提交或重新提交公开审核。
- 图片所有者和平台管理员可通过“编辑图片”进入 M3 编辑器；访客和其他用户不显示编辑入口，服务端仍执行所有权校验。
- 登录用户可以下载有权查看的图片；访客看到登录入口。
- 图片所有者或团队 owner/admin 显示分享管理；重新生成和撤销需要明确二次确认。
- 图片所有者或具备分享管理权的团队 owner/admin 可以主动撤回公开状态。
- 已登录 viewer 可以评论、回复、提及和添加位置批注；解决、删除和管理能力由服务端逐条返回。

## 布局

- 桌面左侧图片舞台，右侧固定信息面板。
- 手机先展示图片，再展示信息。
- 图片舞台使用冷灰背景和白色画框，不添加装饰性边框。
- 当前不提供缩放工具；后续加入时必须使用稳定尺寸且不遮挡图片主体。
- 讨论区域位于图片与信息布局之后。评论和批注使用分段模式，批注模式先在图片上选点再提交。
- 当前版本批注以编号锚点覆盖在图片上；历史版本批注只在讨论列表显示“历史版本批注”，不覆盖当前图片。
- 根讨论按游标分页，“加载更多讨论”追加内容且不重排已显示锚点。

## 状态

- 图片不存在使用 404。
- 非公开且无权限由服务端按不可见资源处理；前端不得泄露资源状态。
- 评论提供 loading、empty、error、提交中、删除、已解决和历史版本状态。
- 图片版本在选点后更新时，提交返回冲突并要求刷新后重新选择，前端不得自动迁移旧坐标。
- 分享弹窗支持固定/自定义有效期、可选密码、一次性完整链接、复制、撤销和重新生成。
