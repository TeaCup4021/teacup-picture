# 图片详情

- 路由：`/pictures/[pictureId]`
- 里程碑：公开查看 M1；下载、评论和分享 M6
- 参考图：[picture-detail.png](../references/picture-detail.png)

## 目标

以大图为主，提供作者、元数据、公开状态和后续互动入口。

## 权限

- 访客可以查看审核通过图片和已有评论。
- 下载、评论和分享需要登录。
- 继续编辑需要图片归属和空间权限。

## 布局

- 桌面左侧图片舞台，右侧固定信息面板。
- 手机先展示图片，再展示信息与评论。
- 图片舞台使用冷灰背景和白色画框，不添加装饰性边框。
- 缩放工具尺寸固定，不能遮挡图片主体。

## 状态

- 图片不存在使用 404。
- 非公开且无权限使用明确的 permission denied。
- 评论接口尚未实现时不展示伪造评论列表。
