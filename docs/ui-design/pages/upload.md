# 上传图片

- 路由：`/upload`
- 里程碑：M1
- 状态：已实现，仅默认个人空间
- 参考图：[upload.png](../references/upload.png)

## 目标

通过本地文件或图片 URL 将单张图片保存到当前用户的默认个人空间。团队目标空间等待 M4。

## 表单

- 来源：本地图片、图片 URL。
- 图片名称、简介、分类和标签。
- 明示 JPEG/JPG/PNG/WebP 和 20 MB 限制。
- 默认私人保存，不自动提交公开审核。

## 布局

- 桌面左侧表单、右侧大预览。
- 手机先选择图片，再显示预览和元数据表单。
- 预览区域保持稳定尺寸，图片使用 `object-fit: contain`。

本地文件上传显示浏览器报告的传输进度，并提供取消按钮；不提供自动重试或断点续传。图片 URL 导入显示处理状态，预览阶段下载的原图在同一用户的短期预览会话内复用，避免提交时再次下载。
