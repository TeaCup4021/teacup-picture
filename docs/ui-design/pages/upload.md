# 上传图片

- 路由：`/upload`
- 里程碑：M1
- 参考图：[upload.png](../references/upload.png)

## 目标

通过本地文件或图片 URL 将单张图片保存到个人空间或有上传权限的团队空间。

## 表单

- 来源：本地图片、图片 URL。
- 图片名称、简介、目标空间、分类和标签。
- 明示 JPEG/JPG/PNG/WebP 和 20 MB 限制。
- 默认私人保存，不自动提交公开审核。

## 布局

- 桌面左侧表单、右侧大预览。
- 手机先选择图片，再显示预览和元数据表单。
- 预览区域保持稳定尺寸，图片使用 `object-fit: contain`。

第一版只展示统一加载状态和最终结果，不伪造精确进度、取消或自动重试。
