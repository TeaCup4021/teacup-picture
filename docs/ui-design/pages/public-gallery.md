# 公开图库

- 路由：`/`
- 里程碑：M1
- 参考图：[public-gallery.png](../references/public-gallery.png)

## 目标

作为网站首页连续展示已审核且仍公开的图片，不制作营销落地页。

## 当前可开发

- 公开图片分批加载。
- 图片标题、作者和公开数据。
- 进入公开详情。
- Loading、错误和空图库状态。

搜索、分类筛选和热度排序仍是待决策项；没有真实接口前不得用前端假数据实现。

## 布局

- 使用顶部导航，不使用业务侧边栏。
- 首屏直接出现标题、必要工具和图片内容。
- 桌面使用内容驱动的瀑布流或混合网格；手机单列。
- 卡片信息叠加在稳定遮罩中，确保各种图片上均可读。

## 动效

- 首屏图片轻量错落进入。
- 悬停时图片最大放大到 `1.025`，操作层渐显。
- 返回页面恢复滚动位置和查询状态。
