# 公开图库

- 路由：`/`
- 里程碑：M1
- 状态：已实现；游标续页与返回位置恢复未实现
- 参考图：[public-gallery.png](../references/public-gallery.png)

## 目标

作为网站首页连续展示已审核且仍公开的图片，不制作营销落地页。

## 当前实现

- 读取公开接口当前批次。
- 图片标题、作者和发布时间。
- 进入公开详情。
- Loading、错误和空图库状态。

游标续页、无限滚动、返回位置恢复、搜索、分类筛选和热度排序仍未实现；没有真实接口前不得用前端假数据或合成指标实现。

## 布局

- 使用顶部导航，不使用业务侧边栏。
- 首屏直接出现标题、必要工具和图片内容。
- 桌面使用内容驱动的瀑布流或混合网格；手机单列。
- 卡片信息叠加在稳定遮罩中，确保各种图片上均可读。

## 动效

- 当前页面整体轻量进入；列表错落进入可在后续性能验证后增加。
- 悬停时图片最大放大到 `1.025`，操作层渐显。
- 返回位置与查询状态恢复是后续交互目标，不是当前行为。
