# 空间分析

- 路由：`/spaces/[spaceId]/analytics`
- 里程碑：M7
- 状态：规划；遗留后端分析接口不能直接作为 `/api/v1` 前端契约
- 产品图：待补充

本页只保存 M7 设计方向。权限、DTO 和 `/api/v1` 分析契约确认前，不得直接调用旧 `/api/**` 分析接口。

## 目标

展示空间使用量、图片分类、图片大小、成员上传行为和空间排名。

## 布局

- 沿用业务侧边栏，图表位于白色无嵌套面板中。
- 同一行指标保持相同高度，图例和单位固定位置。
- 颜色用于区分类别，不使用相近蓝色组成单一色谱。
- 小数据量、无数据和权限不足必须有独立状态。

## 权限

- 个人空间分析仅所有者可见。
- 团队完整分析仅所有者和管理员可见。
- 平台空间排名仅平台管理员可见。

ECharts 配置应复用主题和格式化函数，不在每个页面单独硬编码颜色。
