# 团队空间

- 路由：`/spaces/team`、`/spaces/[spaceId]`
- 里程碑：团队与邀请 M4；实时协作 M5
- 状态：规划，当前团队创建流程仍有后端阻断问题
- 参考图：[team-space.png](../references/team-space.png)

本页只保存 M4/M5 设计方向。必须先完成 `backend-gap-analysis.md` 中的团队空间事务修复、所有权模型和邀请契约，才能进入实现。

## 目标

围绕项目管理图片、版本、成员权限和协作状态。

## 布局

- 沿用浅色业务侧边栏，在侧边栏列出用户可访问的团队空间。
- 空间头部展示名称、容量、图片数、成员和权限入口。
- 图片资产使用规则网格和分页。
- 在线成员面板只在有协作上下文时出现，不长期遮挡资产列表。

## 权限

- viewer、editor、admin 与空间所有者分别判断。
- 隐藏按钮不是授权，所有操作依赖服务端校验。
- 邀请必须经过 pending、接受/拒绝流程，不使用直接添加成员的旧交互。
