# 账号与会话

- 路由：`/login`、`/register`
- 里程碑：M1
- 产品图：待补充

## 目标

完成登录、注册、会话恢复和登录后返回原页面。

## 布局

- 桌面可使用真实图库图片作为一侧视觉区域，表单保持白色、清晰和克制。
- 手机隐藏辅助视觉，表单占据主要视口。
- 不制作营销型 Hero，不展示未实现产品能力。

## 表单与错误

- 标签始终可见，浏览器自动填充属性正确。
- 注册成功后进入登录或按产品规则自动登录，不在浏览器保存 Token。
- 错误信息保留用户输入，不显示后端堆栈或敏感信息。
- 收到未登录错误时保存原 URL，登录成功后返回。
