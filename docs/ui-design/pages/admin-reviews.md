# 管理员公开审核

- 路由：`/admin/reviews`
- 里程碑：M1
- 状态：待审核列表与通过/拒绝已实现；审核历史与撤回未实现
- 参考图：[admin-reviews.png](../references/admin-reviews.png)

## 目标

管理员逐张查看原图、作者和元数据，并明确通过或拒绝。

## 布局

- 浅蓝灰管理侧边栏，主区域使用紧凑列表。
- 左侧待审核列表，右侧固定详情和决策面板。
- 选中行使用浅蓝背景，不改变列表尺寸。
- 详情预览优先，当前展示作者、分类、尺寸和提交时间；格式字段待前端 DTO 适配后展示。

## 操作

- 通过为主要成功操作。
- 拒绝使用危险色描边，并强制填写原因。
- 第一版不提供批量审核和用户举报入口。
- 审核成功后从待审核列表移除并提供反馈。
