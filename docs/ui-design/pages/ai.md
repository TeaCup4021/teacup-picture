# AI 创作与任务

- 路由：`/ai/create`、`/ai/tasks`
- 里程碑：M2
- 状态：已实现开发闭环；生产接入前需完成安全闸门和真实供应商/MinIO 验收
- 参考图：[ai-create.png](../references/ai-create.png)、[ai-tasks.png](../references/ai-tasks.png)

页面已接入 `docs/openapi/m2.yaml` 和真实 `/api/v1/ai/**` 接口，不使用假数据。任务中心通过轮询刷新 queued/running 状态，结果和下载入口仅使用后端返回资源。

## 创建任务

- 当前 OpenAI Images API 接入开放 AI 绘图；扩图入口在兼容端点支持编辑接口前保持不可用。
- 输入模型、比例、清晰度、参考图和提示词。
- 输出参数支持自动/实色/透明背景，以及 PNG、JPEG、WebP；JPEG/WebP 可设置 0 到 100 的输出质量。
- 当前 OpenAI Images 模型的比例严格对应 `1024x1024`、`1536x1024`、`1024x1536`，不对其他比例做近似映射。
- 模型、比例、清晰度、背景、输出格式和压缩能力均由后端返回，禁止硬编码供应商或模型参数列表。
- 显示绘图和扩图两个独立日配额。

## 任务中心

- 展示提示词、参考图、参数、类型、状态、结果、创建时间和失败原因。
- 状态统一为 queued、running、succeeded、failed、cancelled。
- 失败任务展示是否返还额度和可用重试入口。

## 当前实现边界

- 供应商为 OpenAI Images API 兼容端点，默认基址 `https://claudenb.com/`；前端不硬编码模型名称。
- API 密钥只通过后端 `OPENAI_API_KEY` 环境变量注入，不写入前端、数据库或提交配置。
- 扩图源图仅可从当前用户个人空间选择，服务端再次校验所有权。
- 任务创建必须带 `Idempotency-Key`；页面每次新建生成随机幂等键，重试请求复用原键。
- 任务结果自动进入个人空间；下载走 Cookie 鉴权接口，不暴露 MinIO 凭据或预签名 URL。

## 视觉

- 工作区沿用浅色侧边栏。
- AI 画布使用冷灰网格和白色结果框，不使用大面积紫色发光。
- 生成中的动效必须克制并支持减少动态效果。
