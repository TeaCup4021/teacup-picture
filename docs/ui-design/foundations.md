# 视觉基础

## 色彩

| Token                       | 值        | 用途                           |
| --------------------------- | --------- | ------------------------------ |
| `--ui-color-primary`        | `#3370ff` | 主按钮、链接、焦点和关键选中态 |
| `--ui-color-primary-hover`  | `#2b65e8` | 主操作悬停                     |
| `--ui-color-page`           | `#f2f5f8` | 登录后的页面画布               |
| `--ui-color-sidebar`        | `#e7eef6` | 工作区和管理后台侧边栏         |
| `--ui-color-selected`       | `#d9e5ff` | 导航、列表和筛选选中态         |
| `--ui-color-surface`        | `#ffffff` | 卡片、面板、表单和表格         |
| `--ui-color-text`           | `#1f2329` | 标题和主要内容                 |
| `--ui-color-text-secondary` | `#646a73` | 正文和次要信息                 |
| `--ui-color-text-tertiary`  | `#8f959e` | 时间、辅助说明和占位符         |
| `--ui-color-border`         | `#dfe5ec` | 默认边框和分隔线               |

功能状态必须同时使用颜色、图标或文字：成功 `#1d9a72`，警告 `#d48806`，错误 `#d9363e`，信息 `#3370ff`。

## 排版

- 字体：`Inter, PingFang SC, Microsoft YaHei, system-ui, sans-serif`。
- 页面标题：28–32px，字重 700。
- 面板标题：16–20px，字重 600。
- 正文：14px；紧凑工具和表格可使用 12–13px。
- 辅助文字不得低于 11px；实际页面优先使用 12px。
- 不使用负字距，不按视口宽度缩放字号。

## 间距与尺寸

- 基础间距为 4px 倍数：4、8、12、16、20、24、32。
- 桌面侧边栏建议 220–240px。
- 顶部导航建议 60–68px。
- 表单控件高度 36–40px，主要提交按钮 40–44px。
- 图片网格必须使用稳定的 `aspect-ratio`，避免加载时布局跳动。

## 圆角与阴影

- 小控件 6px，面板和图片卡片 8px，大画布或预览面板不超过 12px。
- 普通页面不使用胶囊形按钮，分段控件和状态标签除外。
- 默认阴影只表达层级：`0 6px 18px rgb(31 35 41 / 6%)`。
- 禁止为普通卡片添加彩色发光、强玻璃模糊或多层悬浮效果。

## 主题

- 浅色主题是当前产品图基线。
- 当前 M1 未提供主题切换或全站深色主题。
- 后续若引入主题切换，首次进入跟随系统主题，用户选择后在本地保存偏好，并单独验证文字、边框、图片遮罩和状态色。
- 编辑器始终允许使用深色工作区，不代表整个网站强制深色主题。
