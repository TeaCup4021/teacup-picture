# 公共组件规范

## 应用导航

- 公开页面使用顶部导航，内容发现为第一层级。
- 登录后业务页面使用浅蓝灰侧边栏和白色顶部栏。
- 当前项使用浅蓝底、深蓝文字和图标，不使用渐变填充。
- 侧边栏折叠后必须保留 tooltip 和清晰的当前项状态。

## 图片卡片

- 公开图库突出图片，可将标题和作者叠加在底部暗色遮罩上。
- 个人和团队空间使用规则网格，卡片下方显示名称、状态和更新时间。
- 操作按钮默认隐藏或放入菜单，悬停和键盘聚焦时显示。
- 审核状态必须包含文字，不只显示彩色圆点。

## 表格与列表

- 管理后台和任务中心优先使用紧凑列表或表格。
- 当前选中行使用 `--ui-color-selected`，不改变行高。
- 危险操作与主操作不得使用相同颜色或相邻无间距布局。
- 长标题和提示词采用单行省略，完整内容通过详情区或 tooltip 查看。

## 表单

- 标签始终可见，不用 placeholder 代替标签。
- 聚焦态使用主色边框和浅色 focus ring。
- 表单错误紧邻字段展示；提交失败保留用户输入。
- 上传区必须展示格式、大小限制和最终成功/失败结果。

## 状态与空页面

- Loading：保持最终布局尺寸，图片使用骨架占位。
- Empty：说明当前没有内容，并提供唯一明确的下一步。
- Error：展示可理解原因、重试入口和必要的 `requestId`。
- Permission denied：说明缺少的权限或可联系的角色。
- Success：关键业务操作必须有消息或页面内状态反馈。

## 图标

- 使用 `@ant-design/icons` 中已有图标。
- 熟悉操作优先使用图标按钮并配置 tooltip 和 `aria-label`。
- 不手写重复 SVG，不引入第二套图标库。
