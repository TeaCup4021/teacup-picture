# 动效规范

动效用于解释状态变化和维持空间连续性，不用于装饰页面。

## 时间与缓动

| 场景               | 时长      | 建议缓动                   |
| ------------------ | --------- | -------------------------- |
| 按钮、输入框、悬停 | 120–160ms | `ease-out`                 |
| 下拉菜单、弹层     | 160–200ms | `cubic-bezier(.2,.8,.2,1)` |
| 页面内容进入       | 180–220ms | `cubic-bezier(.2,.8,.2,1)` |
| 图片详情共享转场   | 260–320ms | `cubic-bezier(.16,1,.3,1)` |

## 页面与列表

- 页面进入只允许 `opacity` 和最多 8px 的 `translateY`。
- 首屏图片可以按 30–50ms 间隔依次进入，总时长不超过 400ms。
- 无限滚动新增内容不重复播放强烈入场动画。
- 筛选和排序应尽量保持已有卡片位置连续，不先清空整个页面。

## 图片交互

- 悬停缩放不超过 `1.025`。
- 图片操作层使用渐显，不应改变卡片尺寸。
- 从图库进入详情时优先采用共享元素转场；实现成本过高时退化为普通页面淡入。
- 图片加载失败必须显示稳定占位，不播放循环动画。

## 状态反馈

- 上传、审核和 AI 任务提交后立即展示明确状态。
- 成功提示 2–4 秒后自动消失；失败原因保留到用户处理。
- `queued`、`running` 等长任务可以使用轻量循环进度，不使用大面积呼吸光晕。

## 可访问性与性能

- 必须支持 `prefers-reduced-motion: reduce`。
- 减少动态效果时取消位移、缩放和列表错落动画，只保留必要的瞬时状态变化。
- 优先动画 `transform` 和 `opacity`，避免持续动画阴影、模糊和布局属性。
- 不因为动画延迟按钮可操作时间。
